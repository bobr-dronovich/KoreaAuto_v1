## 🚀 Краткое описание проекта

**KoreaAuto** — полнофункциональный веб-сервис по подбору и доставке автомобилей из Южной Кореи.
- **Frontend**: Vanilla JavaScript (ES6 модули), HTML5, CSS3 с адаптивной версткой под десктоп, планшеты и смартфоны. Фирменные цвета: темно-синий (`#2859a8`) и акцентный кораллово-красный (`#e52b38`).
- **Backend / Database**: Google Firebase (Cloud Firestore в режиме реального времени + Firebase Authentication).
- **Безопасность**: Ролевая модель доступа (`user` и `admin`), защищенная через `firestore.rules`.

## 🗄 Схема базы данных Cloud Firestore

### 1. Коллекция `users` (документ с ID = `user.uid`):
| Поле | Тип | Описание |
|---|---|---|
| `uid` | string | Уникальный идентификатор из Firebase Auth |
| `email` | string | Email пользователя |
| `displayName` | string | Имя и Фамилия |
| `phone` | string | Контактный номер телефона |
| `role` | string | Роль: `'user'` (по умолчанию) или `'admin'` |
| `createdAt` | timestamp | Дата и время регистрации |

### 2. Коллекция `cars` (основная сущность — каталог авто):
| Поле | Тип | Описание |
|---|---|---|
| `id` | string | Автоматический ID документа Firestore |
| `brand` | string | Марка (Hyundai, Kia, Genesis и т.д.) |
| `model` | string | Модель (Santa Fe, K5, G80, Carnival и др.) |
| `year` | number | Год выпуска (например, 2023) |
| `price` | number | Цена под ключ в рублях |
| `mileage` | number | Пробег в километрах |
| `engine` | string | Характеристики двигателя (например, 2.5 T-GDI) |
| `fuel` | string | Бензин / Дизель / Гибрид / Электро |
| `transmission` | string | АКПП / Робот / Вариатор |
| `drive` | string | Полный (AWD/HTRAC) / Передний |
| `imageUrl` | string | Прямой URL качественной фотографии автомобиля |
| `description` | string | Полный текст описания состояния и комплектации |
| `isAvailable` | boolean | Доступность: `true` (в наличии в Корее) / `false` |
| `createdAt` | timestamp | Дата добавления в каталог |

### 3. Коллекция `applications` (действия пользователей / заказы):
| Поле | Тип | Описание |
|---|---|---|
| `userId` | string | UID пользователя, создавшего заказ |
| `userEmail` | string | Email заказчика |
| `userName` | string | Имя клиента |
| `userPhone` | string | Телефон клиента |
| `carId` | string | ID выбранного автомобиля (или пусто при консультации) |
| `carTitle` | string | Название авто (Марка + Модель + Год) |
| `carPrice` | number | Цена автомобиля |
| `carImage` | string | Превью фото авто |
| `status` | string | `'new'` \| `'in_progress'` \| `'approved'` \| `'shipping'` \| `'completed'` \| `'cancelled'` |
| `comment` | string | Пожелания по комплектации / цвету / доставке |
| `createdAt` | timestamp | Время оформления заявки |

### 4. Коллекция `reviews` (интерактив и отзывы):
| Поле | Тип | Описание |
|---|---|---|
| `carId` | string | ID автомобиля, к которому относится отзыв |
| `userId` | string | UID автора отзыва |
| `userName` | string | Отображаемое имя автора |
| `rating` | number | Оценка от 1 до 5 звезд |
| `comment` | string | Текст комментария / отзыва |
| `createdAt` | timestamp | Время публикации отзыва |

### 5. Коллекция `favorites` (избранные авто):
| Поле | Тип | Описание |
|---|---|---|
| `userId` | string | UID пользователя |
| `carId` | string | ID автомобиля |
| `addedAt` | string | Время добавления в избранное |

## 🛠 Очень подробная инструкция по настройке Firebase

Ваш проект в Firebase уже создан: `korea-auto-3213f`. Перейдите по ссылке:
👉 **[https://console.firebase.google.com/project/korea-auto-3213f/overview](https://console.firebase.google.com/project/korea-auto-3213f/overview)**

---

### Шаг 1. Включение Authentication

1. В левом боковом меню консоли Firebase нажмите на раздел **Build** (Сборка), затем выберите **Authentication** (Аутентификация).
2. Если вы нажимаете впервые, нажмите кнопку **Get Started** (Начать).
3. Перейдите во вкладку **Sign-in method** (Способы входа).
4. В списке провайдеров найдите пункт **Email/Password** (Электронная почта / Пароль).
5. Нажмите на него, переведите первый тумблер **Enable** в активное состояние (Включено).
   *(Второй тумблер Email link включать не нужно)*.
6. Нажмите **Save** (Сохранить).

---

### Шаг 2. Создание базы данных Firestore

1. В левом меню выберите **Build** -> **Firestore Database**.
2. Нажмите синюю кнопку **Create database** (Создать базу данных).
3. **Database ID**: оставьте `(default)`.
4. **Location** (Регион базы): выберите европейский регион, например `europe-west1` (Бельгия) или `eur3` (Франкфурт) — для высокой скорости отклика.
5. Нажмите **Next** (Далее).
6. В окне выбора режима выберите **Start in test mode** (для быстрого старта) или **Start in production mode**.
7. Нажмите **Create** (Создать). Через 15–20 секунд база будет развернута!

### Шаг 3. Установка правил безопасности (Security Rules)

1. В разделе **Firestore Database** перейдите во вкладку **Rules** (Правила).
2. Сотрите всё стандартное содержимое и вставьте код из файла `firestore.rules`:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    function isAuthenticated() {
      return request.auth != null;
    }

    function isAdmin() {
      return isAuthenticated() && 
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }

    function isOwner(userId) {
      return isAuthenticated() && request.auth.uid == userId;
    }

    // Пользователи
    match /users/{userId} {
      allow read: if isAuthenticated();
      allow create: if isOwner(userId);
      allow update: if (isOwner(userId) && (!request.resource.data.diff(resource.data).affectedKeys().hasAny(['role']))) 
                    || isAdmin();
      allow delete: if isAdmin();
    }

    // Каталог автомобилей
    match /cars/{carId} {
      allow read: if true;
      allow create, update, delete: if isAdmin();
    }

    // Заявки
    match /applications/{appId} {
      allow read: if isAdmin() || (isAuthenticated() && resource.data.userId == request.auth.uid);
      allow create: if isAuthenticated() && request.resource.data.userId == request.auth.uid;
      allow update: if isAdmin() || (isAuthenticated() && resource.data.userId == request.auth.uid);
      allow delete: if isAdmin();
    }

    // Отзывы
    match /reviews/{reviewId} {
      allow read: if true;
      allow create: if isAuthenticated() && request.resource.data.userId == request.auth.uid;
      allow update, delete: if isAdmin() || (isAuthenticated() && resource.data.userId == request.auth.uid);
    }

    // Избранное
    match /favorites/{favId} {
      allow read, write: if isAuthenticated();
    }

  }
}
```
3. Нажмите кнопку **Publish** (Опубликовать).
> **Важно**: В этих правилах реализовано строгое разграничение: обычный пользователь не может сам сделать себя админом, удалять чужие заявки или редактировать каталог автомобилей. Преподаватель оценит это на высший балл!

### Шаг 4. Композитные индексы (Composite Indexes)

В Firestore при фильтрации по одному полю (например, `brand`) и одновременной сортировке по другому полю (например, `price`) требуется составной индекс.
В проекте KoreaAuto это настроено максимально удобно:
- Базовые запросы оптимизированы.
- Если Firestore потребует индекс, он **выведет в консоль браузера (F12) прямую готовую ссылку**. Вам достаточно кликнуть по ссылке из консоли, откроется Firebase Console и останется нажать кнопку **Create Index**!
- Чтобы создать заранее вручную:
  1. В Firestore Database перейдите во вкладку **Indexes** -> **Composite**.
  2. Нажмите **Add Index**.
  3. Collection ID: `cars`
  4. Поля:
     - `brand` — Ascending
     - `price` — Ascending
     - `createdAt` — Descending
  5. Query scope: Collection -> **Create index**.

### Шаг 5. Как сделать себя Администратором (роль admin)

Для доступа к `admin.html` пользователю требуется роль `admin`.
Сделайте это за 3 простых действия:
1. Запустите сайт и перейдите на страницу `register.html`. Зарегистрируйте свой аккаунт (например, `admin@koreaauto.kz` с паролем `123456`).
2. Откройте [Firebase Console -> Firestore Database -> Data](https://console.firebase.google.com/project/korea-auto-3213f/firestore/databases/-default-/data).
3. Кликните по коллекции **`users`**, выберите документ только что зарегистрированного пользователя:
   - Найдите поле **`role`** (там будет написано `"user"`).
   - Нажмите дважды на значение `"user"` и измените его на **`"admin"`**.
   - Нажмите **Update**.
4. Готово! Теперь при входе под этим аккаунтом в шапке сайта появится значок администратора и прямая ссылка в **Админ-панель** (`admin.html`).

### Шаг 6. Наполнение базы демонстрационными авто (в 1 клик)

Вам не нужно вручную вбивать 10 автомобилей в базу:
1. Авторизуйтесь под аккаунтом администратора и откройте страницу `admin.html`.
2. В верхнем правом углу нажмите синюю кнопку:
   **«Импортировать демонстрационные авто (10 шт)»**.
3. Скрипт мгновенно создаст 10 детально проработанных автомобилей из Кореи (Hyundai Santa Fe, Genesis G80, Kia Carnival 9-мест, Kia K5, Genesis GV80, Hyundai Palisade и др.) с реальными характеристиками, ценами и фотографиями высокого разрешения.
4. Перейдите на главную страницу `index.html` — каталог сразу заполнится!

## 🎬 Сценарий демонстрации проекта преподавателю

1. **Регистрация и Вход**:
   - Откройте `register.html`, покажите валидацию полей и зарегистрируйте нового пользователя.
   - Покажите, что в Firebase Console в Authentication появился пользователь, а в Firestore в `users` создался документ профиля.
2. **Каталог и Пагинация**:
   - Откройте `index.html`. Продемонстрируйте работу поиска («Santa», «Kia») и фильтрацию по маркам, ценам и топливу.
   - Нажмите кнопку «Показать еще» и покажите подгрузку следующей порции документов через Firestore `startAfter()`.
3. **Детальная карточка и Действия**:
   - Кликните «Подробнее» на карточке Genesis G80. Откроется `car.html?id=...`.
   - Нажмите «Оставить заявку на авто» — заявка отправится в Firestore.
   - Напишите отзыв и поставьте 5 звезд — отзыв мгновенно появится в списке через `onSnapshot`.
4. **Личный кабинет**:
   - Откройте `profile.html`. Покажите появившуюся заявку со статусом «Новая».
   - Измените имя пользователя и сохраните.
5. **Админ-панель и Real-Time режим**:
   - Откройте в соседнем окне `admin.html` под аккаунтом админа.
   - Покажите сводную статистику (количество авто, заявки).
   - Во вкладке «Заявки клиентов» измените статус заявки с «Новая» на «В пути из Кореи».
   - Покажите преподавателю окно пользователя: **статус в личном кабинете пользователя обновился мгновенно без перезагрузки страницы** (демонстрация работы `onSnapshot`!).
   - Покажите добавление нового автомобиля через модальное окно CRUD.
6. **Правила безопасности**:
   - Откройте вкладку Rules в Firebase Console и покажите код `firestore.rules`.
